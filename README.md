# Spotify_Top50_Global_Dashboard

🎧 Spotify Top 50 Global – 2025 Analytics Dashboard | Power BI

I built an interactive Power BI dashboard analyzing daily Spotify Top 50 Global data to uncover performance trends across songs, artists, and chart positions.

Because the dataset captures daily rankings, it allows deeper analysis beyond static charts — revealing dominance, consistency, and performance patterns over time.

📊 Core KPIs Designed

The dashboard focuses on executive-level performance indicators:

• Total Songs Tracked
• Distinct Artists
• Average Song Duration (minutes)
• Average / Max / Min Popularity
• Explicit vs Non-Explicit Distribution
• Position 1 Songs & Position 1 Artists
• Songs per Artist
• Album Type Distribution (Singles vs Albums)

All metrics were built using context-aware DAX measures to respond to slicers and filters dynamically.

🔍 What This Dashboard Answers

✔ Who dominates the charts consistently?
✔ Do explicit songs outperform non-explicit tracks?
✔ How competitive is the #1 position?
✔ Are singles driving more chart success than albums?
✔ How does popularity trend month over month?

📈 Key Insights Discovered

• A small group of artists drive a disproportionate share of chart appearances
• Singles dominate the Top 50 distribution
• Explicit songs represent a significant portion of total entries
• Popularity remains relatively stable across months with minor seasonal shifts
• High chart frequency does not always equal highest average popularity
